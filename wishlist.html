Double Agent — Asset Wishlist

Every item below has a generation prompt (or, where marked, a note instead of a prompt) and its own Copy button, and every section has a Copy all button. This mirrors ASSETS-WISHLIST.md in this repo. Cards marked Already obtained and cards marked Wiring note are NOT for regeneration: the asset already exists and is either wired in or waiting to be wired in. Object, character, and weapon textures are already baked into the model files (Agent_Kyle, terror guards, weapon GLBs), so they are not listed here — only environment textures are. Prompts are generation briefs only; a generated model is not a real repo asset until it is checked in.
