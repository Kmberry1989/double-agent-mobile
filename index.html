Mobile version: tap to start — no pointer lock. Left stick moves (edge = sprint), drag anywhere else to look, buttons on the right fire / aim / crouch / jump / reload / use / takedown / weapon / set.

Original stealth prototype. No characters, story, music or assets from any existing game are used here. You are an unnamed operative infiltrating a generic facility courtyard. Get the intel, avoid the patrols and cameras, get out.

Silent start: you begin alone in a walled alcove in the southwest corner, facing northeast into the courtyard. No guard patrol and no security camera is within 30 m of the spawn, so nothing can see or hear you at the start.

Controls

  • W A S D move   Mouse look   Shift sprint (loud)   C crouch / sneak   Space jump
  • Hold Right-mouse to aim.
  • Click fire   R reload   1 pistol   2 rifle   L toggle player loadout (white / black set)   E interact / pick up intel   F silent takedown from behind an unaware guard
  • Q punch   X kick   G wave   T talk   N talk on phone   V male crouch pose (hold)   B female crouch pose (hold) — animation keys, no existing key changed
  • Y cycle weather (Clear → Cloudy → Rain → Fog) — on phones, the WX button below the minimap does the same. Weather is visual only and never changes guard vision, detection, or damage.

Note on controls: the brief asked for both “F aim” and “F takedown”. This build resolves the clash by using right-mouse for aim and F only for takedown, so the two actions cannot conflict. See README for the full note.

Models: guards use enemy-terror1–4.fbx, player weapons are the white_ / black_ sets (press L to toggle sets), and Agent_Kyle.fbx is your player model. The 62 Mixamo FBX clips in assets/animations/ now actually play on Agent_Kyle.fbx via the animation mixer (loops crossfade, actions are one-shots, crouch poses hold) — with a clean fallback to the procedural capsule if the rig or a clip fails.

Click locks the mouse. Press Esc to release it. If you die or win, use the button on the end screen to restart.
